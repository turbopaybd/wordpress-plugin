TurboPay BD provides secure payment gateway integration for WooCommerce stores in Bangladesh via bKash, Nagad, Rocket, Upay, and Cards.

== Description ==

TurboPay BD Gateway for Woocommerce allows you to accept payments from customers in Bangladesh using the most popular mobile financial services (MFS), internet banking, and local cards. This plugin is highly optimized for speed, reliability, and modern WordPress standards.

It bridges your digital checkout system with the TurboPay BD secure merchant API seamlessly, ensuring high success rates and a flawless payment experience.

== Features ==

* Digital Product Support (Instant Order Complete)
* Fast Redirect & Secure Validation API
* Full Support for Cart and Checkout Blocks
* High-performance API Integration
* Easy Configuration Interface for Merchant API Key

== Supported Gateways ==
* bKash
* Nagad
* Rocket
* Upay
* Cellfin
* Local & International Cards

== Installation ==

1. Upload the plugin folder `turbopaybd-gateway` to the `/wp-content/plugins/` directory, or install the plugin through the WordPress admin dashboard directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Navigate to WooCommerce > Settings > Payments.
4. Enable "TurboPay BD" and click on 'Finish set up' or 'Manage'.
5. Enter your API Key provided by [TurboPay BD](https://www.turbopaybd.com).
